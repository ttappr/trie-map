Struct TrieSet 

Source 
pub struct TrieSet<const R: usize, const B: u8> { /* private fields */ }
Expand description

A set implemented using TrieMap. Internally this is a TrieMap with a unit type as the value. This is a convenience type for when you want to use a TrieMap as a set.
